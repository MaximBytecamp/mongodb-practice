# Готовые скрипты

Две программы, которые разбираются в справочнике: они выполняют серию
запросов к MongoDB и печатают результат отчётом в терминал.

| Скрипт | База | Глава | Что делает |
|---|---|---|---|
| `shop_report` | `shop`, `sandbox` | 1.9 | справка по базе, карточка документа, таблицы с проекцией и сортировкой, страницы, вложенные поля, полный цикл записи в песочнице |
| `hh_search` | `hh` | 2.9 | подбор кандидатов под требования, счётчик по каждому требованию, поиск шаблоном, подбор вакансий, период дат, проверка данных |

Каждый скрипт есть на четырёх языках: `.py`, `.rb`, `.go`, `.cpp`.

```bash
# на своём сервере, из корня репозитория
python3 scripts/shop_report.py
ruby scripts/hh_search.rb
go run scripts/shop_report.go
g++ -std=c++17 scripts/hh_search.cpp -o search $(pkg-config --cflags --libs libmongocxx1) && ./search

# в контейнере — язык задаёт имя службы
docker compose run --rm python scripts/shop_report.py
docker compose run --rm cpp    scripts/hh_search.cpp
```

`shop_report` пишет в песочницу `sandbox`: перед запуском верните базы
в исходное состояние командой `docker compose run --rm reset`. Сам скрипт
убирает за собой добавленные товары, поэтому запускать его можно повторно.
`hh_search` только читает данные.

Адрес сервера берётся из переменной `MONGO_URI`, по умолчанию
`mongodb://localhost:27017`.
