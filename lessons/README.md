# lessons — заготовки для примеров из справочника

По файлу на главу и язык: `ch1_4.py` — глава 1.4 на Python, `ch1_4.go` — на Go
и так далее. В заготовке уже есть подключение к серверу и переменные, которыми
пользуются примеры главы: `client`, `db`, `products`, `orders` и `box` —
песочница `sandbox.products`. Глава 1.1 учит подключаться сама, поэтому
для неё заготовки нет: её примеры собраны в папке [`hello/`](../hello/).

Пошагово, с выводом и частыми ошибками — глава 1.0 справочника, §9–§10:
https://maximbytecamp.github.io/mongodb_theory_makarov/temy/00-uchebnye-bazy/index.html

## Как работать

Пока пример не вставлен, заготовка только проверяет связь с сервером — её можно
запустить сразу:

```
Заготовка главы 1.4 подключилась к серверу. Замените проверочные строки примером из главы.
```

1. **Проверьте состояние баз.** В начале заготовки написано, меняет ли глава
   данные. Если меняет (1.2, 1.3, 1.7, 1.8) — перед главой верните базы
   в исходное состояние: `docker compose run --rm reset`, `bash stend/load.sh`
   или `stend\load.ps1`.
2. **Вставьте пример** из главы в отмеченное место заготовки — вместо
   проверочных строк. Python и Ruby — в конец файла, под чертой. Go и C++ — внутрь
   фигурных скобок в конце `main`; пример, который объявляет функцию или тип, — выше `main`.
3. **Запустите файл.** Каждый пример — один раз и по порядку. Следующий пример
   вставляйте вместо предыдущего, а не под ним: иначе предыдущий выполнится ещё
   раз, и числа разойдутся с книгой.

Выводы в справочнике получены ровно так, поэтому совпадут с вашими. Отличаться
будут только `_id`, которые выдаёт сервер, и текущие дата и время.

## Запуск

Из папки `lessons`:

| Язык | Windows | macOS и Linux |
|---|---|---|
| Python | `python ch1_4.py` | `python3 ch1_4.py` |
| Ruby | `ruby ch1_4.rb` | `ruby ch1_4.rb` |
| Go | `go run ch1_4.go` | `go run ch1_4.go` |
| C++ | через Docker | `g++ -std=c++17 ch1_4.cpp -o ch1_4 $(pkg-config --cflags --libs libmongocxx1) && ./ch1_4` |

Через Docker — из корня репозитория, одинаково во всех системах:

```bash
docker compose run --rm python lessons/ch1_4.py
docker compose run --rm ruby   lessons/ch1_4.rb
docker compose run --rm go     lessons/ch1_4.go
docker compose run --rm cpp    lessons/ch1_4.cpp
```

Контейнер переходит в папку файла, поэтому пути вида `../stend/seed/…`
в примерах работают так же, как при запуске на компьютере.

Заготовки сгенерированы скриптом `tools/examples.py` из репозитория справочника:
он же прогоняет все примеры глав на стенде и проверяет, что выводы в книге
совпадают с настоящими.
